## demo12 v4 修订：VLAN 改标准 802.1Q（4B）+ 层数可选真正落地 ✅

- **修后端 headerSize**：原「逐字段 ceil(w/8) 求和」→ 4B 的 802.1Q 被算成 6B、20B 的
  IPv4/TCP 算成 22B。改为 **header 总宽 ceil/8**（真实以太网语义）。这是 802.1Q 能落地的
  前提，也顺带让 IPv4/TCP 回到 20B。
- vlan_h = TPID16 + PCP3 + DEI1 + VID12（4B）；otag 6B 带 nextType；新增链末端
  etype_h(2B) 承载 802.1Q 缺失的"下一层类型"，isIpv4/isL3 由它判定。
- 层数可变的行为边界：trunk 上联 0..3 层加一层、**满 4 层饱和不加**；access 用户口
  1..4 层剥一层、**0 层无可剥**；泛洪不编辑。doPush/doPop 放 resolve（由 rtHit/macHit
  直接判定，避免读本 action 刚写的 fwdType）。
- TB 按层数组织 8 个用例（0/1/2/4 层 × L2 剥/L3 打/饱和 + OpaqueTag + TTL + 泛洪）
  **38/38**；IR 级 **55/55**（新增 otag 存在性、0 层边界）。
- 坑：出包槽位是 **33 位（valid + 32B 标签）**，TB 期望值只写 32 位会差一个最高位
  （parser 无条件 extract ⇒ valid 恒 1）。

## p4flow 一键流程补齐（9 项，全部实测通过）

1. **smoke TB 自动生成**（原「空转骨架」）：没自带 TB 时生成带 **runtime 表 mock** 的
   testbench——见 `tbl_X_key_vld` 后按契约延时回 `hit=0`（miss 走 default 表项），发一包
   断言 `pkt_out_vld` 400 拍内到达；sim 步由 WARN 变 OK。表清单优先用 AST 契约，
   退化时从端口名反推。
2. **报告可追溯**：生成时间 + 输入 SHA256 前 16 位 + git commit + 关键配置
   （stages / pkt-window / wct / sim-timeout）。
3. **表接口契约导出** `contract/tables.json`：key 位段、actId→action、args 形参 LSB 偏移、
   latency 契约。数据源 = Parser 解析期算好的 `P4Program.tableContracts`（与生成 IR 同源，
   避免两处漂移）。⚠️ 字段路径首段是**形参名**（hdr/meta），要经形参→struct 别名表解析。
4. **golden 对拍步**（`--golden <官方可编译变体.p4>`，缺省试 `testcases/golden/<base>.p4`）→
   调 `scripts/golden_sim.py`，帧写入报告。
5. **`--chisel-sim`**：chisel 步顺带生成 `<Top>Sim.scala`（svsim 入口）。
6. **样本级断言钩子** `verify` 步：自动发现 `scripts/<base>_verify.py`（base = 文件名主干
   第一个 `-` 之前）或 `--verify "<cmd>"`；脚本声明了 `--ir-dir` 时自动补该参数。
7. **vlint 步**：`verilator --lint-only`（要带 `xls_fifo_wrapper.sv`；`-Wno-fatal` + 常见告警放行）。
8. **分模块画像**：报告 3.2.1 按模块列行数/寄存器/位宽/线网。
9. **II 判定上下文 + 「边界与未验证项」固定小节**。
- 坑：Scala 编辑时把注释与 `def` 挤到同一行 ⇒ `def` 被注释、报「unmatched closing brace」。
